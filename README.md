## 🔄 Integration Flow

```
┌─────────────────────────────────────────┐
│    User Opens http://localhost:5173     │
├─────────────────────────────────────────┤
│  1. App checks localStorage for token   │
│  2. If found, restores session silently │
│  3. Router checks if route requiresAuth │
│  4. Redirects to login if needed        │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│    User Enters: admin / Admin#99        │
├─────────────────────────────────────────┤
│  1. Frontend validates form              │
│  2. POST /api/auth/login                │
│  3. Backend validates credentials       │
│  4. Returns access + refresh tokens     │
│  5. Frontend stores tokens              │
│  6. Fetches user info                   │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│  User Navigates the Application         │
├─────────────────────────────────────────┤
│  1. All API calls include Authorization │
│  2. Backend validates token             │
│  3. If expired, auto-refresh occurs     │
│  4. Request succeeds silently            │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│    User Clicks Logout                   │
├─────────────────────────────────────────┤
│  1. POST /api/auth/logout               │
│  2. Backend revokes token               │
│  3. Frontend clears localStorage        │
│  4. Redirect to login                   │
└─────────────────────────────────────────┘
```

## ✨ Key Features Implemented

### Authentication
- ✅ JWT-based with 15-minute access token
- ✅ Refresh token rotation (7-day expiration)
- ✅ Automatic token refresh on 401
- ✅ Secure password hashing (bcrypt)

### Session Management
- ✅ Token storage in localStorage (secure)
- ✅ Session persistence (survives reload)
- ✅ Automatic session restoration
- ✅ Logout clears all data

### Developer Experience
- ✅ Type-safe with TypeScript
- ✅ API client with error handling
- ✅ Composable pattern for state
- ✅ Pinia store for state management
- ✅ Development proxy (no CORS issues)

### Security
- ✅ Account lockout (5 attempts, 15 min)
- ✅ Authorization headers
- ✅ CORS configuration
- ✅ Secure token handling
