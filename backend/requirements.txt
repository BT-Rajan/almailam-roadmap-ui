# zoneinfo (used for the Kuwait-time report-filing cutoff, see
# status_report_service.py) needs an IANA tz database on the host --
# present by default on most Linux distros but not guaranteed in
# minimal/slim container images. tzdata bundles it directly so the
# lookup never silently falls back to server-local time.
tzdata==2025.2
# HTML -> PDF rendering. Two callers: a filled government-form template
# (see app/services/pdf_render.py), and document_template_service.
# _docx_to_pdf's own HTML (rendered directly from python-docx above,
# not through a generic docx->HTML library -- see that function's own
# docstring) for the Quotation/Contract "Print"/"Email" PDF, so those
# show the admin's real uploaded-template content -- including its
# images and direct formatting -- instead of a separate hardcoded
# preview. A LibreOffice-headless docx->PDF conversion was tried for
# the latter first and does not run reliably in this app's container,
# hence a pure-Python HTML round-trip instead of shelling out to it.
# Unlike tzdata above, this is NOT a pure-Python wheel: it needs Pango,
# Cairo, and GDK-Pixbuf shared libraries already installed on the host
# (e.g. Debian/Ubuntu: libpango-1.0-0, libpangocairo-1.0-0, libcairo2,
# libgdk-pixbuf-2.0-0). install.sh deliberately never runs apt-get
# itself (see its own header comment), so these must already be
# present on the server -- if `pip install -r requirements.txt`
# succeeds but importing weasyprint fails, that's the missing piece,
# not a Python problem.
